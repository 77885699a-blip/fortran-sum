第 1 題　Fortran 程式編寫

17 / 20

題目

寫一個能計算 1 加到 N 總和的 Fortran 程式，並說明在環境中如何進行編譯與執行。

解題過程

  1. 用 implicit none 要求所有變數都要宣告，避免打錯變數名稱卻不報錯。
  2. 把 n、i、total 宣告成 64 位元整數。32 位元整數最大約 21 億，N 稍大就會溢位。
  3. 用 read *, n 從鍵盤讀入 N。
  4. 先把 total 歸零，再用 do 迴圈從 1 累加到 N。
  5. 安裝 gfortran，以 -Wall 開啟警告後編譯，再執行。

答案

program sum_n
  implicit none
  integer(kind=8) :: n, i, total

  print *, 'Enter N:'
  read *, n

  total = 0
  do i = 1, n
    total = total + i
  end do

  print *, 'Sum of 1 to ', n, ' = ', total
end program sum_n
# 安裝（Ubuntu / Debian / WSL）
sudo apt update && sudo apt install gfortran
# 編譯與執行
gfortran -Wall -o sum_n sum_n.f90
./sum_n

得分原因：邏輯正確，宣告完整，考慮到 64 位元整數，編譯與執行指令清楚。

扣分原因：沒有在工作區實際編譯執行（無 gfortran）；沒有檢查 N 是否為正整數，N 為 0 或負數時只會輸出 0。

題目

指導如何初始化 Git 並將原版程式進行第一次 commit：
  • 為程式碼加上詳細註解，並指導如何編譯測試加註解後的版本。
  • 測試成功後，指導進行第二次 commit。

解題過程

  1. git init -b main 建立儲存庫，並設定作者名稱與信箱。
  2. 把 sum_n.f90 加入暫存區，完成第一次 commit（原版）。
  3. 加入註解：程式用途、作者、64 位元的原因、每個區段的作用。
  4. 編譯並測試加註解版；註解不影響結果，所以輸出應與原版相同。
  5. 用 git diff --stat 確認只改了註解，再做第二次 commit。

答案

git init -b main
git config user.name "你的名字"
git config user.email "你的GitHub信箱"

# 第一次 commit（原版）
git add sum_n.f90
git commit -m "Add Fortran program to sum 1..N"

# 加註解後先編譯測試
gfortran -Wall -o sum_n sum_n.f90
echo 94664 | ./sum_n        # 應輸出 4480683780

# 第二次 commit
git diff --stat
git add sum_n.f90
git commit -m "Add detailed comments to sum_n.f90"
git log --oneline
8d6cb03 Add detailed comments to sum_n.f90
ffa0cbb Add Fortran program to sum 1..N

上面兩行是我在工作區演練時的實際 git log --oneline 輸出；你自己的 commit 編號會不同。建議在 .gitignore 加入 sum_n，避免提交執行檔。

得分原因：Git 步驟已實際執行，兩次 commit 都成功；註解完整；有用 diff 確認只改註解。

扣分原因：加註解版的編譯測試因為沒有 gfortran，沒有在工作區完成。

第 4 題　推送 GitHub

15 / 20

題目

指導如何將本地 Git 儲存庫（Repository）推送到自己的 GitHub 雲端專案庫。

解題過程

  1. 在 GitHub 按 New repository 建立空白儲存庫，不要勾選 README、.gitignore、License，以免與本地歷史衝突。
  2. 用 git remote add origin 加入遠端位址。
  3. 把分支名稱統一成 main，再用 git push -u origin main 推送。
  4. 驗證身分：密碼欄貼上 Personal Access Token，GitHub 已不接受帳號密碼；也可改用 SSH。
  5. 重新整理 GitHub 頁面，確認看得到兩筆 commit。

答案

git remote add origin https://github.com/<帳號>/fortran-sum.git
git branch -M main
git push -u origin main

# 若使用 SSH
git remote set-url origin git@github.com:<帳號>/fortran-sum.git

得分原因：步驟完整，包含 Token 與 SSH 兩種驗證方式，也提醒不要勾選初始化檔案。

扣分原因：推送需要你的 GitHub 帳號與憑證，所以沒有真的推送，整條流程沒有實測；沒有說明推送被拒絕（non-fast-forward）時怎麼處理。

答案（核心程式，完整內容見 score.html）

function readScore(input) {
  var v = parseFloat(input.value);
  if (isNaN(v)) return 0;                  // 空白或非數字視為 0
  return Math.min(20, Math.max(0, v));     // 限制在 0~20
}

function update() {
  var total = 0;
  ids.forEach(function (id) { total += readScore(document.getElementById(id)); });
  var title = "姓名：" + NAME + " / 學號：" + ID + "/ 總得分：" + total;
  document.getElementById("totalScore").textContent = total;
  document.getElementById("pageTitle").textContent = title;
  document.title = title;
}
